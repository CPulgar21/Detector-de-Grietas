# Fuentes usadas:

- SDNET2018 (carpetas CW/UW, muros): <https://www.kaggle.com/datasets/harishmulchandani2/sdnet2018>
- Concrete Crack Images for Classification (Ozgenel): <https://www.kaggle.com/datasets/arnavr10880/concrete-crack-images-for-classification>
- Fotos propias: <Alrededor de 200 fotos propias; superficies planas, rugosas, grietas superficiales y peligrosas; redimensionadas a 227x227>
- Clase no_aplica: <https://www.kaggle.com/datasets/prasunroy/natural-images>

## Criterios de etiquetado
- sana: pared limpia o concreto sin grieta visible.
- superficial: linea visible sin grosor suficiente para considerarse peligrosa.
- peligrosa: grieta abierta visible con profundidad considerable.
- no_aplica: imagenes que no son una superficie constructiva (personas, animales, objetos).

Ni SDNET2018 ni Ozgenel etiquetan severidad: las etiquetas superficial/peligrosa son propias.
